# GESTOCK 1.0

Adaptação inicial do SpawnVault 2.4.1. Código em desenvolvimento, sem deploy nem instalador validado.

Ler GESTOCK.md para funcionalidades implementadas, preparação de servidor, migrações, configuração e limitações. A gestão de stocks está no botão Gestão de stocks; o catálogo herdado foi preservado.

Desenvolvimento: instalar Node.js 24; executar npm ci, npm run check, npm test e npm start. Para compilar Windows: npm run dist -- --publish never. Não publicar antes de concluir a unificação dos acessos e validar o servidor.
